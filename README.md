# 오늘운 (oneulun)

사주로 오늘 하루 정해주는 앱. 점심·마실 것·하지 말 것, 그리고 앞으로 7일. **로그인·백엔드·DB·API 키 없음.** 순수 정적 사이트.

```bash
npm install
npm run dev     # 개발
npm test        # 사주 계산 검증
npm run lint    # oxlint
npm run build   # dist/ 배포용
```

## 화면

- **오늘** — 오늘 일간이 내 일간에 만드는 십신으로 점심/음료/피할 행동 추천. **추천마다 왜 하필 오늘 그건지 근거가 붙는다**("편관(壓力)은 밖에서 눌러오는 기운 → 매운맛으로 태우면 풀린다"). `날짜+일간` 시드로 뽑아서 자정까지 안 바뀐다.
- **내 카드** — 십신을 비겁/식상/재성/관성/인성 5축 캐릭터로 재해석. 강점·약점·취급 설명서·찰떡/상극까지 MBTI식으로 풀어준다. 오행 분포는 개인 기준으로 해석한다.
- **파티** — 여러 명 오행을 합산해 파티 밸런스 진단.

## 공유와 식별

**계정이 없다.** 식별자는 URL과 localStorage 그 자체다. 서버에 유저 테이블이 없으니 식별할 대상도 없다.

| 링크 | 여는 화면 |
| --- | --- |
| `?t=card&b=19930512-14` | 그 사람의 캐릭터 카드 (`x`면 시 모름: `19930512-x`) |
| `?t=party&p=철수~19930512-14,영희~19950203-9` | 그 멤버 구성의 파티 진단 |

받은 사람은 앱 설치도, 가입도, 자기 생일 입력도 필요 없이 바로 결과를 본다.

두 번 입력하지 않기 위한 규칙:

- 내 생일은 첫 입력 때 localStorage에 저장된다. 이후 재방문 시 안 묻는다.
- 파티 멤버도 저장된다. 저장된 내 생일은 파티에서 **`+ 나`** 버튼으로 한 번에 넣는다.
- `?b=`로 열어본 **남의 생일은 저장하지 않고** "친구 사주 보는 중" 배너만 띄운다. 내 생일을 덮어쓰지 않기 위해서다.
- `?p=`로 받은 파티도 보기만 할 땐 저장하지 않고, 멤버를 넣거나 빼는 순간부터 내 목록이 된다.

**파티 궁합은 링크를 이어 던지는 방식이다.** 서버가 없으니 A가 넣은 파티원이 B 화면에 저절로 나타날 방법이 없다. 대신 링크가 곧 파티 상태다:

1. A가 자기를 넣고 링크를 만들어 단톡방에 던진다.
2. B가 링크를 연다 — 로그인도 설치도 없이 A의 파티가 바로 보인다. "친구가 보낸 파티예요" 안내가 뜬다.
3. B가 자기 생일을 넣으면 A+B가 담긴 **새 링크**가 만들어진다. B가 그걸 다시 던진다.
4. C가 이어서 같은 걸 한다.

즉 최신 링크를 가진 사람이 전체를 본다. 중간 링크를 가진 사람은 그 시점의 파티를 본다 — 링크가 스냅샷이라 당연한 결과고, 이걸 실시간으로 만들려면 서버가 필요하다.

폰과 PC 사이 동기화는 안 된다. 그건 계정이 있어야 하는 유일한 기능이라 뺐다. 지금은 자기한테 링크를 보내면 된다.

## 구조

- `src/saju.ts` — 팔자·십신·오행 계산 + URL 인코딩. [lunar-javascript](https://github.com/6tail/lunar-javascript)가 절기 기반 간지를 계산하고, 십신은 오행 상생/상극 + 음양으로 직접 구한다(라이브러리가 노출하지 않음).
- `src/data.ts` — 십신 10개 문구(추천 70개 + 각각의 근거), 캐릭터 5종, 오방색 테이블. **문구 고치려면 여기만 보면 된다.**
- `src/ui.tsx` — 낙관·패널·생일 입력·공유 버튼.
- `src/tabs/` — 화면 3개.

## 주의

- 사주의 해는 양력 1월 1일이 아니라 **입춘**에 바뀐다. `saju.test.ts`가 2024년 입춘(2/4 16:27) 경계를 고정해 둠.
- **생시는 생략 가능하다.** `시 모름`이 기본값이고, 이 경우 시주를 통째로 뺀다(정오로 대충 채워 틀린 결과를 내지 않는다). 오행 합계도 8이 아니라 6이 되고, 내 카드가 그 사실을 알려준다.
- 생일은 localStorage에만 저장. 네트워크로 나가는 개인정보가 없다.
- 번들 170KB(gzip)의 대부분이 lunar-javascript다. 절기 데이터라 쪼갤 수 없고, 한 번 캐시되면 끝이라 그냥 뒀다.
